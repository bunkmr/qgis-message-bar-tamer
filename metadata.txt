name=Message Bar Tamer
description=Tame or suppress the noisy QGIS MessageBar banners (red / yellow). Filter by level, hide completely, or auto-dismiss. Optional keyword blocklist, toolbar button + Ctrl+Shift+M toggle. Works on QGIS 3.x (PyQt5) and 4.x (PyQt6).
about=Patches QgsMessageBar.pushMessage / pushWidget AND uses a widgetAdded signal + event-filter double net, so it catches banners from both the Python side and the C++ core (e.g. tile network timeouts, some CRS prompts). Default mode is "threshold + keep Critical" which kills the yellow noise while keeping real red errors. Three modes (threshold / off / reduce), keyword blocklist, and a log fallback that writes suppressed messages to the Log Messages panel so you never miss a real error.
